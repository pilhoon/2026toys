## 마법 물 정렬 퍼즐 입력 파싱 규칙

아래 규칙은 `magicsort/solver.py`의 `parse_initial_state`가 사용하는 텍스트 입력 형식을 정리한 것이다. 공백 줄은 무시하고 앞뒤 공백을 제거한 뒤 처리한다.

- **모드 헤더**: 첫 유효 줄이 `(부분)` 혹은 `partial`이면 제거하고 `partial` 모드로 설정한다. 그 외에는 `full` 모드.
- **잠금 표기**: 한 줄의 앞/뒤에 `"고"`가 있거나 줄이 `"고..."`로 시작하면 해당 병은 `locked_out`에 들어간다.
- **넣기 제한**: 한 줄에 `/색`을 붙이거나 `(색)`을 적으면 그 병에는 그 색만 받을 수 있다. `/f`(대소문자 무관)는 제한 대신 잠금으로 처리된다. 제한 색에 숫자는 쓸 수 없다.
- **용량**: 기본 용량은 4. 줄 끝이 `1`이면 용량 1, `1x`이면 용량 1이면서 잠금 처리된다. 용량은 `tube_caps`로 반환된다.
- **비활성 병**: 줄이 `-`이면 해당 병은 비어 있고 용량 0이다. 제한 색을 함께 적을 수 없다.
- **색 표기**:
  - 한 글자 영문 → 색 약어 매핑: `r(적)`, `o(주)`, `y(노)`, `l(연)`, `s(하)`, `b(파)`, `v(보)`, `p(핑)`, `g(녹)`, `e(회)`, `w(갈)`, `m(자)`.
  - 별칭 정규화: `레/적 → 빨`, `청 → 파`. 제한 색에도 동일하게 적용된다.
  - `색+숫자`는 해당 색을 숫자만큼 반복해 확장한다(예: `빨2` → `["빨","빨"]`).
- **미지 블록**:
  - `?`는 한 개의 미지 블록을 의미하며 순서대로 `?1`, `?2`처럼 고유 번호가 붙는다.
  - `?숫자`는 그 개수만큼 연속된 미지 블록을 생성한다.
  - `???`처럼 연속된 `?`도 같은 규칙으로 길이에 맞춰 확장된다.
- **토큰 구분**:
  - `빈` 또는 빈 문자열은 빈 병으로 취급한다.
  - 쉼표(`,`)가 있으면 쉼표 기준으로 토큰을 분리해 순서대로 쌓는다.
  - 쉼표가 없으면 공백을 모두 제거한 뒤 붙어 있는 문자열을 압축 토크나이즈한다(색/미지/반복 숫자 조합을 순서대로 읽음).
  - 줄 중간의 일반 공백은 무시되므로 `파 빨`과 `파빨`은 동일하게 처리된다.

파싱 결과는 `(state, restricted_put, locked_out, tube_caps, mode)` 튜플로 반환된다. `state`는 각 병을 위에서 아래 순서로 담은 튜플들의 튜플이며, `restricted_put`/`locked_out`은 1-based 인덱스를 키로 사용한다.
